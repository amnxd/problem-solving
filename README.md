

# 🧠 Problem Solving & Competitive Programming

A curated collection of algorithmic solutions and data structure implementations designed for competitive programming and technical interview preparation. This repository serves as a personal archive of coding practices, contest submissions, and problem-solving techniques across multiple difficulty levels.

## 📂 Repository Structure
The codebase is organized by platform and difficulty to streamline navigation and reference:
- `Codeforces/` – Solutions to Codeforces contest problems.
- `dsa2getHer/` – Structured Data Structures & Algorithms practice, categorized by difficulty (`easy/`, `mid/`).
- `archived/` – Historical solutions, language experiments (C++, JS), and reusable boilerplates.
- `c/` – C language fundamentals and templates.
- `.vscode/` – Preconfigured workspace settings for seamless C++ development.

## 🛠️ Getting Started & Usage
These solutions are written primarily in **C++** and require a standard C++ compiler (e.g., `g++`).

1. **Clone the repository**
   ```bash
   git clone https://github.com/amnxd/problem-solving.git
   cd problem-solving
   ```

2. **Navigate to a problem directory**
   ```bash
   cd Codeforces
   ```

3. **Compile and run**
   ```bash
   g++ 282A.cpp -o 282A
   ./282A
   ```

### 💻 IDE Configuration
The repository includes a `.vscode` directory preconfigured for **VSCode** with MinGW (`g++`) on Windows. The `tasks.json` file automates compilation, and `settings.json` handles C++ file associations. For Linux/macOS, ensure `g++` is installed via your package manager (`sudo apt install g++` or `brew install gcc`) and adjust the task paths if necessary.
